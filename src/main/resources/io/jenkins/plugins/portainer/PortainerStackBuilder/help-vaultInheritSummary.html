Readiness line for Inherit from System (HashiCorp Vault Plugin):

  • Vault Plugin is not installed. — plugin missing or inactive on this controller.
  • Vault Plugin is not configured. — plugin present but System Vault URL/credentials are incomplete.
  • Vault Plugin is present and configured. — ready to use Inherit on this step.

When not ready: install and enable the HashiCorp Vault Plugin, then set Manage Jenkins → System → Vault (URL and credentials). Folder/job policy templates still come from that plugin at build time.

Soft dependency — Manual and Not connected work without the Vault Plugin.
