Vault connection types:

  • Not connected (default): disable Vault. No Vault HTTP or Vault Plugin calls; Manual fields and path are ignored. Stack Env[] uses step env only.
  • Inherit from System (optional): use the official HashiCorp Vault Plugin System configuration. Soft dependency — install the Vault Plugin for Inherit.
  • Manual (optional): self-contained HTTP AppRole on this step (vaultUrl + Username/Password). Vault Plugin is not required.

Path and KV mount stay on this step for Inherit/Manual. Vault wins over step text env on key collisions.
