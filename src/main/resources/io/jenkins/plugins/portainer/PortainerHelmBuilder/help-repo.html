Helm chart repository URL (e.g. https://charts.example/helm or https://gitlab.example/api/v4/projects/{id}/packages/helm/stable).

Portainer fetches index.yaml from this URL. The install API has no username/password fields, so this step cannot pass private chart-repo credentials. Use a repository Portainer can reach without HTTP auth, or install with Helm outside Portainer.

Do not put credentials in the URL (https://user:token@… is rejected).
